# TREND LOG

27SS 여성복 실무자용 트렌드 트래킹 서비스 · 2팀 검색어팀 (성균관대 「인공지능과 패션 비즈니스」)

무신사 · SSENSE · 후르츠패밀리 · 구글 트렌드에서 모은 표본을 실루엣 · 소재 · 컬러로 정리하고, 출처와 함께 보여줍니다.

## 화면 구성

| 화면 | 주소 | 내용 |
|---|---|---|
| 1. 진입 · 메인 | `#home` | 서비스 소개, 문장 입력 + 복종 · 세부 품목 · 브랜드 컨셉 · 채널 선택 |
| 2. 핵심 작업 · 분석 | `#result` | 조건 요약 바(수정 · 재조회), 실루엣 · 소재 · 컬러 카드, 채널별 근거 상품 |
| 3. 결과 · 상세 | `#export` | 선택 항목 리포트, CSV 다운로드, 텍스트 복사 |

## 조회 범위

- 대상: 27SS 여성
- 복종 · 세부 품목: 아우터(라이트자켓 · 데님자켓 · 가디건) / 상의(반팔 · 블라우스 · 롱슬리브) / 하의(스커트 · 쇼츠 · 팬츠)
- 브랜드 컨셉: 컨템 · 페미닌 · 스트리트 · 클래식 · SPA

## 채널별 수집 기준

| 채널 | 가져올 데이터 | 파악 (지금) | 예측 (27SS 후보) |
|---|---|---|---|
| SSENSE | 여성 · 복종별 신상품 상위 20개 | 해외 디자이너가 지금 내놓는 것 | 국내에 퍼지기 전의 신호 |
| 후르츠패밀리 | 복종별 인기 상품 상위 20개 | 중고 시장 인기 | 재유행 신호 |
| 무신사 | 여성 · 복종별 판매순 상위 20개 + 올해 3~5월 봄 랭킹 기사 | 국내에서 지금 팔리는 것 | 이미 퍼졌는지 확인 |
| 구글 트렌드 | 키워드별 최근 12개월 추이 + 최근 5년의 같은 시즌(3~5월) | 지금 관심도 | 상승 속도, 매년 봄에 반복되는지 |

'퍼지기 전 후보'는 해외 디자이너 → 검색 → 국내 판매 순으로 퍼진다는 가정에 따른 구분입니다. 표본이 5건 미만이면 '판단 보류'로 표시합니다.

## 데이터 파일 (엑셀에서 CSV로 저장해서 교체)

> 지금 들어 있는 데이터는 화면 흐름 확인용 **예시**입니다. 실제 수집 데이터로 교체하면 화면이 그대로 바뀝니다.

`data/meta.json` — 수집일, 예시 여부(`is_sample`), 채널 설명

`data/trends.csv` — 키워드 한 줄씩

| 열 | 뜻 | 예 |
|---|---|---|
| category | 복종 | 상의 |
| item_type | 세부 품목 | 블라우스 |
| concept | 브랜드 컨셉 | 페미닌 |
| attribute_type | 실루엣 · 소재 · 컬러 | 소재 |
| keyword | 키워드 | 시어(시스루) |
| mention_count | 언급 건수 (분자) | 12 |
| sample_count | 유효 표본 수 (분모) | 60 |
| channels_found | 등장한 채널, `\|`로 구분 | SSENSE\|후르츠패밀리 |

'퍼지기 전 후보 / 이미 퍼진 흐름 / 판단 보류'는 화면 코드가 channels_found와 mention_count로 계산합니다.

`data/search_trends.csv` — 구글 트렌드 키워드별 최근 12개월 관심도 (`monthly_interest`, `|`로 구분)

`data/evidence.csv` — 근거 상품 한 줄씩 (item_type · concept · keyword로 trends.csv와 연결)

| 열 | 뜻 |
|---|---|
| item_type, concept, keyword | 어느 키워드의 근거인지 |
| channel | 무신사 · SSENSE · 후르츠패밀리 |
| brand, product_name, price | 브랜드 · 상품명 · 가격 |
| url | 원본 상품 페이지 |

## 하지 않는 것

로그인 · 결제 · 발주 · 전체 웹 실시간 크롤링 · 기획안 자동 작성. 트렌드 노출 빈도이며 판매량 순위나 성능 검증이 아닙니다.

## 로컬에서 보기

데이터를 파일에서 불러오므로 파일을 바로 여는 대신 간단한 서버로 열어야 합니다: `python3 -m http.server` 후 `http://localhost:8000`. Vercel · Netlify에 이 저장소를 연결하면 그대로 배포됩니다.
